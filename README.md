# পোশাকঘর — দোকানের ওয়েবসাইট ও অ্যাডমিন প্যানেল

এই ফোল্ডারে আছে:

- `index.html` — গ্রাহকের ওয়েবসাইট
- `admin/index.html` — আপনার অ্যাডমিন প্যানেল
- `data/shop.json` — প্রোডাক্ট, দাম ও সেটিং (অ্যাডমিন প্যানেল এটাই বদলায়)
- `images/` — প্রোডাক্টের ছবি

## ধাপ ১: GitHub-এ ওয়েবসাইট তোলা

1. github.com-এ অ্যাকাউন্ট খুলুন (না থাকলে)।
2. উপরের ডানে **+ → New repository** চাপুন। নাম দিন যেমন `shop`। **Public** রাখুন (ফ্রি GitHub Pages-এর জন্য Public লাগে)। Create চাপুন।
3. রিপোজিটরির পেজে **uploading an existing file** লিংকে চাপুন।
4. এই ফোল্ডারের সব ফাইল ও ফোল্ডার (`index.html`, `admin`, `data`, `images`, `.nojekyll`, `README.md`) টেনে এনে ছেড়ে দিন। তারপর নিচে **Commit changes** চাপুন।
5. রিপোজিটরির **Settings → Pages** এ যান। **Source** এ “Deploy from a branch” বাছুন, Branch **main**, ফোল্ডার **/ (root)** দিয়ে Save করুন।
6. ১–২ মিনিট পর আপনার ওয়েবসাইট চালু হবে:
   - দোকান: `https://আপনার-ইউজারনেম.github.io/shop/`
   - অ্যাডমিন: `https://আপনার-ইউজারনেম.github.io/shop/admin/`

## ধাপ ২: অ্যাক্সেস টোকেন তৈরি (একবারই)

টোকেন হলো অ্যাডমিন প্যানেলের চাবি। এটা দিয়েই প্যানেল আপনার রিপোজিটরিতে পরিবর্তন সংরক্ষণ করে।

1. GitHub-এ উপরের ডানে প্রোফাইল ছবি → **Settings** → একদম নিচে **Developer settings**।
2. **Personal access tokens → Fine-grained tokens → Generate new token**।
3. নাম দিন (যেমন `shop-admin`), মেয়াদ বাছুন (যেমন ১ বছর)।
4. **Repository access** এ “Only select repositories” বেছে শুধু আপনার `shop` রিপোজিটরি দিন।
5. **Permissions → Repository permissions → Contents** এ **Read and write** বাছুন। আর কোনো অনুমতি দেবেন না।
6. **Generate token** চেপে যে টোকেন (`github_pat_…`) পাবেন সেটা কপি করে নিরাপদ জায়গায় রাখুন। পরে আর দেখা যায় না।

## ধাপ ৩: অ্যাডমিন প্যানেল ব্যবহার

1. অ্যাডমিন লিংক খুলুন। ইউজারনেম ও রিপোজিটরির নাম নিজে থেকে বসে যেতে পারে, না বসলে লিখুন। ব্রাঞ্চে `main`, টোকেন ঘরে টোকেন দিন।
2. **দোকান সেটিং** ট্যাবে প্রথমে আপনার **WhatsApp নম্বর** দিন। এই নম্বরেই গ্রাহকের অর্ডার আসবে।
3. **প্রোডাক্ট** ট্যাবে দাম, নাম, সাইজ, বিবরণ বদলান। ছবির ঘরে চাপ দিয়ে ছবি বদলান বা নতুন রঙ যোগ করুন। নতুন প্রোডাক্টে অবশ্যই ছবি দিতে হবে।
4. উপরের **সংরক্ষণ করুন** চাপুন। ১–২ মিনিটের মধ্যে ওয়েবসাইটে আপডেট দেখা যাবে।

## নিরাপত্তা

- অ্যাডমিন পেজের লিংক সবাই খুলতে পারে, কিন্তু টোকেন ছাড়া কিছু বদলানো যায় না।
- টোকেন কাউকে দেবেন না, কোনো ফাইলে বা ছবিতে লিখে রাখবেন না।
- “এই ডিভাইসে মনে রাখুন” শুধু নিজের ফোন বা কম্পিউটারে চালু করুন।
- টোকেন হারালে বা কারও হাতে গেলে GitHub-এর Developer settings থেকে সেটা মুছে নতুন তৈরি করুন।
- রিপোজিটরি Public, তাই প্রোডাক্টের তথ্য ও ছবি সবাই দেখতে পাবে। WhatsApp নম্বর ওয়েবসাইটে এমনিতেই দেখানো হয়।

## জেনে রাখুন

- অর্ডার এই ওয়েবসাইটে জমা হয় না। গ্রাহক অর্ডারের মেসেজ আপনার WhatsApp (বা মেসেঞ্জারে) পাঠালে তবেই আপনি অর্ডার পান।
- GitHub-এর মেনুর নাম কখনো সামান্য বদলাতে পারে। না মিললে একই অর্থের কাছাকাছি অপশন খুঁজুন।
- অ্যাডমিন প্যানেল ব্যবহার না করলেও `data/shop.json` ফাইল সরাসরি GitHub-এ এডিট করা যায়।
